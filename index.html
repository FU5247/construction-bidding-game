ゲームの遊び方・ルール

🎯 ゲームの目的

全ターンを生き残り、最も多くの資金（Y）を持っていた企業が勝利となります。資金がマイナスになると「破産」となり、実質脱落となります（他の企業の市場競争は最後まで進行します）。

🔄 ターンの流れ

  1. 景気決定： コイントスにより「好景気」か「不景気」が決まります。景気により人件費が変動します。不景気時はコストが高騰します。
  2. 入札フェイズ： 大・中・小いずれかの工事を選び、10Y単位で入札します。一番安い金額（最安値）を提示した1社のみが落札（受注）できます。同額の場合は抽選になります。利益が出ない場合は「パス」も重要です。
  3. 雇用フェイズ： 落札できた場合、工事に必要な人数を満たすように人を雇います。
  4. 清算： 獲得した入札額から、人件費を引いた額が資金に反映されます。

👷 雇用とコストについて

人数は 正社員:1人 / 発注・派遣:1人 として計算されます。

  • 👨‍💼 正社員（好景気20Y / 不景気30Y）： 一度雇うと解雇できません。毎ターン固定費としてかかりますが、長期的に見るとコストパフォーマンスに優れます。
  • 👷 発注・派遣（好景気30Y / 不景気45Y）： そのターン限りの人員です。正社員より割高ですが、次ターン以降の固定費にはなりません。

🤖 CPUの戦略について

設定から各CPUの性格を変更できます。

  • 自律適応型： 過去の「1位かつ利益を出した勝者」のデータを学習し、限界利益も考慮して適正価格で受注を狙う賢いAI。
  • 完全外注特化： 正社員を雇わず、すべて派遣で賄う身軽な戦略。
  • 完全正社員特化： 積極的に正社員を雇い、固定費をかけても受注を狙う戦略。
